 What technologies are used :
 
1. **Frontend**:
   - **React**: A JavaScript library for building user interfaces.
   - **TypeScript**: Provides type safety and improves code quality.
   - **Tailwind CSS**: A utility-first CSS framework for styling.
   - **shadcn/ui**: A component library built on Tailwind CSS for reusable UI components.

2. **Build Tool**:
   - **Vite**: A fast build tool for modern web applications, used for development and production builds.

3. **Routing**:
   - **React Router**: Handles navigation between pages (e.g., project feed, create project, project details).

4. **State Management**:
   - **React Query**: Manages server state and API calls efficiently.

5. **Other Libraries**:
   - **Lucide Icons**: Provides SVG icons for UI elements.
   - **Radix UI**: A library for accessible UI primitives (e.g., scroll areas, tooltips).
   - **Zod**: A schema validation library for form validation.

6. **Development Tools**:
   - **ESLint**: Ensures code quality and consistency.
   - **TypeScript ESLint**: Adds TypeScript-specific linting rules.
   - **PostCSS**: Processes CSS with plugins like autoprefixer.
